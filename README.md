# Fight Life

Демонстрация блоков по предоставленным макетам. Чистые HTML, CSS и JavaScript, без сборки и сторонних JS-библиотек. Десктопная ширина — 1440 px, адаптив отсутствует.

Откройте `index.html` в браузере или запустите `node serve.mjs` и откройте http://127.0.0.1:4173.

Прокручивайте страницу: текст и фон фиксируются, предметы движутся с небольшой разницей в скорости. После последнего предмета фиксация заканчивается. Блин и мяч постоянно вращаются по часовой стрелке. При системной настройке уменьшения движения вращение отключается.

Высота окна вычисляется по левой колонке и пересчитывается после загрузки шрифта и изменения текста. В `styles.css` размеры и позиции предметов заданы в классах `.product--…`, скорость — в атрибутах `data-speed` в HTML. `data-bottom` обозначает нижнюю видимую границу предмета в исходной композиции.

После первого блока с отступом 120 px идёт «Ein paar Worte zu Fight Life!». Заголовок фиксируется вместе с блоком: сначала три абзаца сменяются снизу вверх, затем четыре фотографии прокручиваются горизонтально. После последнего фото весь блок плавно исчезает, открывая видеозаставку. Прокрутка назад возвращает все состояния в обратном порядке. Пороговые значения этапов находятся в `script.js` рядом с `firstChange` и `galleryStart`.

Видеозаставка использует чистый кадр `image 1в.png`. Заголовок — видимый HTML-текст, кнопка — отдельный элемент с `Play.svg`, пока без запуска видео. По новому макету видеоблок имеет боковые поля 64 px. Общий фон сайта — #000000.

Блоки размещены в общей фиксируемой сцене `.page-scene`. Во время анимации первого блока второй стоит на месте с отступом 120 px. После неё видимая часть блока с фотографиями фиксируется нижним краем у низа окна: скрытое видео не добавляет пустоту под фотографиями. Затем идут абзацы, горизонтальная галерея и видеозаставка. Во время появления более высокого видео сцена плавно поднимается, сохраняя его нижний край у низа окна. Как только видео проявилось полностью, фиксация заканчивается и страница обычно прокручивается к преимуществам с отступом 120 px. На невысоком окне предусмотрен доскролл до нижнего края видео. Прокрутка изменяет только transform и opacity, без изменения отступов или высоты документа. Появление видео растянуто на 1100 px прокрутки, заголовок и кнопка проявляются с небольшой задержкой.

Для следующих обычных блоков используйте разметку после `main.page-blocks` и отступ 120 px. Добавление новых этапов внутрь фиксированной сцены требует расширения последовательности в `script.js`.

При фиксации галереи до нижнего края окна остаётся 40 px (`galleryBottomGap` в `script.js`). Этот отступ относится к фотографиям; переход к видео и обычная прокрутка после него сохранены.

Добавлен блок «Unsere Vorteile»: три карточки со скошенными рамками по `Frame 33564.svg`. Иконки встроены в HTML как SVG, их отдельные версии сохранены в `assets/benefit-*.svg`. В первой по очереди поднимаются столбцы и опускаются звёзды; во второй появляется телефон, затем сообщения слева и справа; в третьей кошелёк выезжает справа и монеты падают сверху. При появлении блока анимации запускаются один раз через IntersectionObserver. Каждое наведение или фокус клавиатурой повторяет анимацию соответствующей карточки с отменой предыдущего запуска. При системном уменьшении движения иконки остаются статичными.

Кнопка открывает демонстрационное окно; подключение формы заявки не входит в текущий макет. Для загрузки Overpass нужен интернет.

## Сохранения и откат

В `backups/` хранятся ZIP-снимки всей рабочей версии, включая изображения. Имя содержит дату и время по Москве и описание этапа. Для отката распакуйте нужный архив в отдельную папку и откройте его `index.html`; текущий проект при этом сохранится. Чтобы заменить текущий проект, скопируйте содержимое выбранного архива в папку проекта с заменой файлов.

Перед следующими правками создавайте снимок командой `powershell -NoProfile -ExecutionPolicy Bypass -File .\save-version.ps1 -Label before-change`. После завершения — с `-Label after-change`. Снимки не включают папку backups и не перезаписывают предыдущие архивы.
